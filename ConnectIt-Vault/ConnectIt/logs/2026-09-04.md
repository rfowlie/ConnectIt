## Request

"Help organize and plan for this project's code-to-blueprint bridge" — catalogue every
value the game's UI would want to display, chart where each is stored / how it's read in
C++ / whether Blueprint can read it, and recommend a read-only home for each; then close
the gaps the catalogue found.

## Overview

Two Explore passes (runtime data model; framework/UI/content-asset layout) plus direct
reads produced a full inventory, then a Plan pass designed concrete fixes for every gap
found, respecting the project's conventions at the time (single-source-of-truth
replication, module-ownership for new code, `Duplication.md`'s anti-duplication
discipline — **all pre-dating** the [[ConnectIt/decisions/2026-09-08-board-architecture-overhaul|2026-09-08 board-architecture overhaul]], see Flags below).

Wrote `Source/ConnectIt/Docs/UIValueCatalogue.md` (by-UI-value reference, cross-linked
with the existing by-system `RuntimeStateAccess.md`) and closed 7 gaps plus 2
correctness bugs found along the way:

- **Bugs fixed**: `AConnectIt_GameState::IsLocalPlayerTurn()` returned `false` on every
  remote client (read server-only `GetControllerAtIndex`/`ServerControllers`) — rerouted
  to the already-correct `UConnectIt_GameUtilityLibrary::IsLocalPlayerTurn`.
  `GetFactionScore`/`GetAllScores` `check()`-crashed on a null board component instead of
  degrading like their siblings.
- **Gap 6** — `GetActiveParticipant(bool&)` / `GetParticipantBySlot(int32, bool&)` on
  `UTurnBasedParticipantManagerComponent` + `ATurnBasedGameState` passthroughs.
- **Gap 2** — `UTurnBasedMechanicsLibrary::GetParticipantDisplayName` (static; `USTRUCT`
  methods can't carry `UFUNCTION`), `FTurnParticipantInfo::GetDisplayName()` now delegates
  to it.
- **Gap 5** — replicated `ReplicatedTurnStartServerTime` (a timestamp, not per-tick) +
  `ATurnBasedGameState::GetTurnTimeRemaining`/`GetTurnTimeRemainingFraction`, so any
  client can render any participant's countdown, not just the active one. Added the field
  to `FTurnBasedParticipantManagerInfo`/`GetInfo()` and updated
  `DWidget_TurnBasedParticipantManagerComponent`'s seeding in the same pass.
- **Gap 4** — new `UConnectIt_BoardStateLibrary` (`UBlueprintFunctionLibrary` over
  `const FConnectItBoardState&` — works on live/previous/hypothetical states, unlike a
  component-bound wrapper); resolved the `TODO: remove, let's try not repeat ourselves`
  debate on `UConnectIt_BoardStateComponent` in its favour.
- **Gap 3** — `FConnectItBoardState::TargetScore` (rides the existing single replicated
  snapshot), `IConnectIt_WinCondition::GetTargetScore()` widened onto the interface,
  `UConnectIt_ScoreThresholdWinCondition`/`UConnectIt_BoardRulesComponent`/
  `AConnectIt_GameState` wrappers, stamped from `CheckWinCondition` and
  `AConnectIt_BoardManager::InitialiseBoard`. **Deliberately did not** collapse
  `UConnectIt_GameRulesLibrary::ConnectIt_Score_Max` into this — it's a MinMax AI
  normalisation bound, not a duplicate UI accessor; left with a comment explaining the two
  may diverge.
- **Gap 7** — `DisplayName`/`Description`/`Icon` on `UTurnBasedAction` (required promoting
  `SlateCore` to a public dependency in `UnrealTurnBasedMechanics.Build.cs`).
- **Gap 1 — built, then removed same session** (see below).

Also: deleted two dead commented-out blocks (`ConnectIt_BoardManager.h`'s stale registry
getters, `ConnectIt_BoardStateComponent.h`'s `TODO` block), added a `Duplication.md` #8
entry for `Plugins/UnrealUIMechanics/` + `AConnectIt_GameMode_Play` (both confirmed
unreferenced, parked pending an owner decision), and made ~11 corrections to
`RuntimeStateAccess.md` (stale `*RegistryComponent` type names, the `IsLocalPlayerTurn`
bug, new turn-timer/`BoardManagerSubsystem`/`ParticipantComponent` rows).

**Follow-up in the same session**: asked to remove the faction-visuals concept entirely
("white-box phase, keep the codebase lean"). Deleted the 6 new files
(`ConnectIt_FactionVisualsDataAsset.h/.cpp`, `ConnectIt_FactionVisualsSubsystem.h/.cpp`,
`ConnectIt_UISettings.h/.cpp`), reverted the `DeveloperSettings` module dependency and the
`Conventions.md` note about it, and rewrote `UIValueCatalogue.md`'s Gap 1 / §H back to
open/deferred with the design intent recorded for later (this is what
[[ConnectIt/decisions/2026-09-09-faction-visuals-subsystem-built-then-removed|the later decision note]] documents).
