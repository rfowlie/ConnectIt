## Overview

- **Self-applying events:** every board event applies its own change to a board (`ApplyTo`, plus `ApplyAll` for a
  list).
  - `Scored` now carries each tile's new multiplier; `TileMultiplierDestroyed` carries the value it took.
  - The base event has `CauseIndex` (always -1 until powers fire).
- **Display board:** `UConnectIt_BoardStateComponent` keeps the board as the player has seen it.
  - Each board event is applied as its queue entry completes.
  - When the queue drains it catches up to Current, with a warning on any tile or score mismatch.
  - Game logic still reads Current.
- **Tile actors on a shift:** `UConnectIt_TileRegistry::ShiftTiles` re-keys tile actors the way pieces are re-keyed
  (from the owner's 2026-10-22 plan edit).
- **Build and tests:** built; 54/54 tests pass, one of them new (`ConnectIt.Board.Events.Replay`: before + events =
  after for every operation and for scoring). Throughput 368,438 nodes/s (366k-379k earlier today).
