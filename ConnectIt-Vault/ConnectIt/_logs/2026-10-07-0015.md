## Request

`FConnectItMinMaxRules` hardcodes "place a piece" in `GenerateMoves` and `ApplyMove`, and `ApplyMove` also scores. Move
"which moves exist" and "how a move changes the board" onto a board-action type; scoring comes afterwards.

## Overview

Added `FConnectItBoardOperation` (Place Piece, Swap Pieces) to the rule set. The Mediator and the MinMax search both
run a move as: operation applies → `FConnectItRuleSet::ResolveBoardChange` scores the touched tiles → win state. The
search is given Place Piece only. Build clean; 12/12 `ConnectIt.AI` tests (9 ported, 3 new); throughput 407k nodes/s
(was 386k). Not yet played in PIE. Plan + status: [design/board-operations](../design/board-operations.md).
