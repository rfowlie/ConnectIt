## Request

Slice 1's `SkinTypes.h` was over-engineered — row shapes are project territory. Trim the
plugin to a project-agnostic core, then build the skin subsystem and save slot.

## Overview

Planned with the owner (one table per category, tiny preset base row, runtime-only
level-forced skins), then implemented in `UnrealSkinMechanics`. Removed `USkinDataAsset`,
`FSkinCatalogRow`, `FSkinCategoryDefinition`, `FSkinSelection` and the owner/faction context
idea; `SkinTypes.h` now holds only `FSkinPresetRowBase`. `USkinSettings` became
`SkinTables` (category tag → table) + `PresetTable` + default preset + save slot. Added
`USkinSaveGame` and `USkinSubsystem` (`UGameInstanceSubsystem`): precedence resolution
(level-forced > override > preset > default, candidates must exist as table rows),
`GetSkinRowHandle`/`FindSkinRow<T>`, player mutators that broadcast `OnSkinChanged` on
change, runtime-only `SetLevelForced`, and `SaveSelection`/`ReloadSelection`.
