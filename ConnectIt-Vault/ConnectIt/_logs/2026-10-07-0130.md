## Request

Operations should carry all their own data and be what actions send, removing the linker structs; and every request
type should be an operation so the Mediator has no fall-through.

## Overview

A `FConnectItBoardOperation` is now the request payload itself, with its data. All eight kinds of board change are
operations; the Mediator has a single path. Request structs, the move value and the rule set's operation list are
gone. Build clean; 19/19 `ConnectIt` tests (13 ported, 6 new operation tests); throughput 362k nodes/s (395k before).
Not yet played in PIE. Plan + status: [design/board-operations-revision-2](../design/board-operations-revision-2.md).
