## Request

Board-visualizer plan, Stages 2-5 and 7, built back to back for one commit (owner). Stage 6 is the owner's, in the
editor.

## Overview

- **Stage 2, `UConnectIt_VisualHandle`:**
  - `Hold(Holder)` / `Release(Holder)` (Blueprint passes self), `IsComplete`, `GetHoldCount`;
  - completes when sealed with no holds left;
  - a hold or release after completion, or a release without a hold, is ignored (warned);
  - `ReleaseAllBy` for an actor leaving play;
  - the timeout logs the holders that never released, then completes.
- **Stage 3, `AConnectIt_BoardVisualizer`** (an actor, one per map, spawned by the board registry subsystem from the
  level config's new **Visualizer Class**):
  - it binds every board event struct (reflection; 22 kinds) on the event queue;
  - per event: C++ bookkeeping, the event's Blueprint-native function (22 + `OnBoardEvent`), then the handle;
  - when the handle completes, the rest of the bookkeeping, then the queue moves on;
  - the bookkeeping:
    - pieces are spawned from the level config's piece class, mapped and placed (tile + `PieceOffset`);
    - moves, swaps and shifts re-key the registries;
    - removed / cleared pieces and removed tiles are unmapped, then pooled / destroyed after the visuals;
    - added tiles are spawned;
    - moved tiles and pieces are snapped onto their cells.
  - Helpers: `GetTileAt`, `GetPieceAt`, `GetArrivingPieces`, `GetLeavingPieces`, `GetLeavingTiles`,
    `GetPieceLocation`.
- **Stage 4:**
  - tile hooks take the handle (defaults hold nothing); `FinishPendingReactions` → `ReleaseVisualHolds`;
  - pieces gain `OnPlaced`, `OnMoved`, `OnSwapped`, `OnCaptured`, `OnRemoved`, `OnClearedByScore`;
  - `UConnectIt_TileVisualizer` and `UConnectIt_TileReaction` are removed;
  - the piece registry's unused `HandleBoard*` stubs are replaced by `MapPiece`, `UnmapPiece`, `SwapPieceActors`,
    `ShiftPieceActors`.
- **Stage 5:**
  - queued events are stamped (`PlayIndex`, `PlayChangeId`, local), and the board state component keeps each change
    until its events have played;
  - `FConnectItBoardEvent::FindCause`;
  - library `GetActiveBoardEventIndex`, `GetBoardEventCause`, `GetBoardEventCauseTag`, `GetBoardEventCauseAs<T>`,
    also on the visualizer.
- **Tests:**
  - new `ConnectIt.Visuals.Handle`, `.Events` (every struct tagged; an event played end to end through a real queue),
    `.HookDefaults`;
  - cause checks in `ConnectIt.Board.TilePowerChain`; the old `ConnectIt.Board.TileHooks` removed;
  - test-world gotchas found:
    - the timer manager ticks once per engine frame, so the tests advance `GFrameCounter`;
    - actors ignore Blueprint-callable calls until `InitializeActorsForPlay`.
- Editor build clean, **73/73**; Game target clean.
- **Expected until Stage 6:** Blueprints using the old Reaction pins fail to compile (e.g. `CI_GridTile_Push`), and
  `CI_PieceVisualHandler` / registry Blueprints that still do bookkeeping now double it.
