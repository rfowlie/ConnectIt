## Request

Add a simple, generic UI to the skin plugin that visualizes every configured category with a
dropdown for choosing a skin — purely to verify setup, nothing project-specific.

## Overview

Planned with the owner (runtime code-built widget; resolution-source + issue APIs; console
command + Blueprint toggle), then implemented in `UnrealSkinMechanics`. `USkinSubsystem` gained
`GetSkinResolution` (winning ID + `ESkinSource`) and `GetConfigurationIssues` (catalog
validation). New `USkinDebugWidget` / `USkinDebugRow` build their widget tree in C++; the
`SkinMechanics.ToggleDebug` console command (a file-scope `FAutoConsoleCommandWithWorld` in
`SkinDebugWidget.cpp`, not module startup) and `ToggleDebugWidget` open/close it.
