## Request

`FConnectItBoardChangeEvent` is a monolithic struct that grows with every event and mixes player operations with
their side effects. Split it into individual polymorphic events, categorised, processed one at a time.

## Overview

A board change is now an ordered list of small event structs (operation events and result events). Each is queued
with its own data as payload on the game event queue and played one at a time; listeners read the event being played.
Build clean; 20/20 `ConnectIt` tests; throughput 392k nodes/s (unchanged). Not yet played in PIE, and
`CI_PieceVisualHandler` needs rewiring. Plan + status: [design/board-events](../design/board-events.md).
