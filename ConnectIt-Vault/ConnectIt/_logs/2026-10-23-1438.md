## Request

Discuss consolidating the language around skills, actions and powers. The owner set the standard: the plugin
conforms first, then the project.

## Overview

- **Decided (owner):** [player actions, tile powers, board operations](../_decisions/2026-10-23-player-actions-tile-powers-board-operations.md).
  - **Names:** Player Action, Tile Power, Board Operation (produced by both); "skill" retired.
  - **Uses:** Player Action uses are **permanent** (every level) or **item** (one-time). Each has match and turn uses,
    set by the level's set-up or the save; -1 match uses = unlimited.
- **Surveyed for the implementation:**
  - 17 source files across UnrealTurnBasedMechanics and ConnectIt use the permanent / numbered action configs.
  - 5 loadout assets hold them (`Content/_ConnectItNetworked/Game/Data/ActionLoadout/`).
- **Still open, before a plan:**
  - unlimited turn uses;
  - an action with both kinds of uses in one match (which is spent first);
  - max held uses and cooldowns;
  - migrating the 5 loadouts;
  - the action and operation tag roots;
  - the plugin's class names;
  - renaming Adventure Stage 1's "skill" names.
- **No code changed.**
