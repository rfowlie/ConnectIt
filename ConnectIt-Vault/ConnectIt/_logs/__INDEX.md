# ConnectIt/_logs/

ConnectIt-domain maintenance passes — automated changes scoped to the game module. One
timestamped note per run. Governed by [[_core/_schema/_logs|_core/_schema/_logs.md]].
Vault-wide passes go in `_core/_logs/`.

Generated by Dataview from each log's `run` and `summary` properties. Newest first. (Needs the Dataview plugin.)

```dataview
TABLE WITHOUT ID file.link AS Log, run AS Run, summary AS Summary
FROM "ConnectIt/_logs"
WHERE run
SORT run DESC
```
