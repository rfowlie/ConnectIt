## Request

Adventure-hub-map plan, Stage 1: the hub game mode, its component, and the node component.

## Overview

- **`UConnectIt_MapNodeComponent`** turns any actor into a map node:
  - `NodeData`, `bIsStart`, `bIsExit`;
  - a state (the adventure plan's Hidden / Available / Gated / Completed), a focus flag and `OnStateChanged`;
  - Hidden hides the actor and its collision, and a node starts Hidden;
  - it adds itself to the hub on `BeginPlay` only if the hub has already discovered its nodes, and removes itself on
    `EndPlay`.
- **`UConnectIt_AdventureHubComponent`**, on the new **`AConnectIt_GameMode_AdventureHub`**:
  - discovers the world's node components once, on its `BeginPlay`;
  - keeps node → component (→ actor) and actor → node maps;
  - `AddNode` is add-or-update; it rejects a node with no data, or a second node naming the same data asset (an
    error; the first is kept);
  - a second Start or Exit is an error (the first is kept);
  - queries both ways, plus the start and exit nodes; `GetAdventureHub` finds it from any world context (null outside
    hub maps).
- The reveal walk (states from progress) is Stage 2.
- Test: `ConnectIt.Adventure.HubDiscovery`. Editor build clean, **78/78**; Game target clean.
