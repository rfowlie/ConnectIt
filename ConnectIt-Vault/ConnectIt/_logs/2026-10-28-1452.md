## Request

Hover-component plan, Stage 2: the subsystem binds the components.

## Overview

- **`UGridHoverSubsystem`:**
  - `RegisterTile` binds the tile's `HoverComponent` and enables it;
  - `UnregisterTile` disables it (a hover on it ends and is relayed) and unbinds it;
  - new relays `OnGridTileHoverEnded` and `OnGridTileClicked`, next to `OnGridTileHoverChanged` (now raised from the
    component);
  - the piece path (`RegisterPiece`, `UnregisterPiece`, `OnGridPieceHoverChanged`) is marked deprecated for Blueprint
    and keeps working.
- **`AGridTileBase::OnGridTileBeginCursorOver`** is deprecated and forwarded from the component's hover begin for one
  release. The subsystem no longer listens to it, so the tile Blueprint's manual broadcast no longer reaches it
  (removed in Stage 4).
- **`AGridPieceBase`:**
  - its primitives ignore the cursor trace channel, so the tile under it is hovered (`bBlocksCursorTrace` default
    false; `CursorTraceChannel` default Visibility);
  - `OnGridPieceBeginCursorOver` is deprecated.
- **`UTurnBasedPlayerAction`:**
  - `HandleTileClicked(Tile)` (Blueprint-native) does nothing by default, because the selection input already selects;
  - hover end clears its hovered tile through `HandleHoverCleared`;
  - hover begin is unchanged.
- **`UGridTileComponent`:** its unused cursor delegates are removed (no asset references the class).
- Tests: `UnrealGridMechanics.Hover.Subsystem` checks, in a throwaway world:
  - register binds and enables the component;
  - begin, click and end reach the relays, naming the tile;
  - unregistering during a hover relays the end, then unbinds.
- Editor build clean, 71/71 (`ConnectIt+UnrealGridMechanics`); Game target clean.
