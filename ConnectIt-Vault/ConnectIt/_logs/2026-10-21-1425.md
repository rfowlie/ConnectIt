## Overview

- **The GameState mirror:** the GameState mirrors "board not settled" as a replicated `bBoardChangeResolving`, with
  `IsBoardChangeResolving` and the `OnBoardChangeResolvingChanged` event (fires on the server and on clients).
- **Who updates it:** the GameMode publishes it on commit, release and the end of each drain. It stays on while level
  changes wait.
- **Server check:** `ProcessBoardRequest` now refuses on `!IsBoardSettled()`, the same test the clients see.
- **Client check:** the player controller doesn't send a request while the mirror says busy. It answers locally through
  the refusal path, so the action re-enables.
- **Build and tests:** built; 47/47 tests pass. PIE and the UI wiring are the owner's.
