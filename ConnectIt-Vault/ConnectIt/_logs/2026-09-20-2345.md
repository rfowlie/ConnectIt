## Request

The owner realised X/Y were backwards relative to UE (+X forward, +Y right), swapped the values in
`GridDirectionVectors`, and asked for a quick check of the rest of the code.

## Overview

Audited every consumer of the direction table and grid coordinates. Two problems found: the swap
left `UpLeft` as (-1,-1) (a duplicate of `DownLeft`; the owner corrected it to (1,-1) while this
ran), and `UGridTileRegistryBase::GetTilesByDirection` still encoded the old picture, so Board Shift
Up/Down would have collected the perpendicular line. Fixed the function and its comment, and
refreshed the table's header comment. Everything else already agreed: world<->grid conversion,
`CalculateGridPositionFromSize`, `LineScoringRule`, the shape library, the Board Shift distance sort,
neighbours, closest-direction lookup. `GetGridDirectionFromDegrees` is now consistent with UE yaw
(0 = +X = Up), which it wasn't before.
