## Request

Rebuild the Classic-mode MinMax AI end to end, following the 2026-09-24 check-in's
scope decision (MinMax stays for Classic, place-piece-only; Adventure gets its own,
still-undesigned AI).

## Overview

Explored the existing MinMax code, the AI-adjacent plugin surface
(`UnrealGameIntelligence`, `UnrealAIMechanics`), and the level-config precedent, then
planned and implemented in plan mode. Rebuilt `FConnectItMinMaxNode`/
`UConnectIt_MinMaxTreeBuilder` around a real `FConnectItBoardState`; extracted
`UConnectIt_LineScoringRule`'s algorithm to a thread-safe static function the search
calls directly (no UObject/BlueprintNativeEvent dispatch off the game thread); added
`IConnectIt_ScoringRule::GetMinimumConnectLength()` (mirrors `GetTargetScore`); wired a
real decision-to-request bridge on `AConnectIt_AIController` via a new
`UConnectIt_AIActionsComponent` (this AI's turn-started hook) and a turn-end loop
(`ActionsComponent::CanEndTurn`, since nothing on the AI's action stack ever completes to
trigger it automatically); deleted the older, unused `UConnectIt_MinMaxManager` node
model and the fully dead `ConcreteMinMaxExample.h`. Required one small plugin change:
`ATurnBasedAIController`'s constructor didn't accept/forward `FObjectInitializer` (needed
for the `SetDefaultSubobjectClass` technique), unlike `ATurnBasedPlayerControllerBase`,
which already did for the same reason -- brought the two in line.
