## Request

Carry out the approved plan [design/ai-director-pipeline](../design/ai-director-pipeline.md): the director owns the AI's
setup, the coordinator becomes a fixed pipeline, strategies cache a best-so-far answer, selectors pick among answers, the AI
profile goes, win conditions become data assets. Built stage by stage; this note grows with each stage.

## Overview

- **Stage 0** -- plan moved into the vault; `design/composable-ai.md` marked partly superseded. Owner committed (b069416).
- **Stage 1** -- the MinMax search reports each completed depth's ranking as it runs, into a thread-safe progress holder the
  game thread can read at any time. Built; 32/32 tests pass. Owner committed (05abbe9).
- **Stage 2** -- candidates gain optional `Confidence` / `StrategyScore` / `Tags` / `SourceLabel`; every strategy keeps a
  best-so-far answer (`PublishBestSoFar`, `GetBestSoFar`, `IsDecisionFinished`); the MinMax strategy answers from its
  search's progress while it runs, with confidences. Built; 35/35 tests pass. Owner committed (31a6bb1).
- **Stage 3** -- selectors: a base class with one pipeline (endorse -> rank -> keep MaxCandidates) and the four first ones
  (First Available, Top N with mistake chance, Greedy Scorer, Weighted by Confidence). Built; 39/39 tests pass. Owner
  committed (4e36f27).
- **Stage 4** -- the coordinator is a fixed pipeline owned by the controller (not a strategy); the director owns the setup
  (starting loadout, strategies, selector, think times) and gains `OnMatchStarted` / `OnOpponentTurnStarted`; MinMax's mistake
  settings and the strategy's `MinThinkSeconds` are gone (Top N selector / director). Built; 39/39 tests pass (Coordinator and
  Director tests rewritten). Owner committed (c74b2a9).
- **Stage 5** (2026-10-19) -- the AI profile is gone: a match preset names its AI director, the menu picks presets, and the
  profile's loadout-vs-strategy validation moved onto the director (run by the preset). Built; 39/39 tests pass.

  (with the selectors and director that replace them), not Stage 2.
- **Between Stage 4 and Stage 5 the AI profile is ignored**: the opponent comes only from the preset's AI Director. To play
  against the AI now, each preset needs an AI Director with a **Starting Loadout** (a preset with none gets the default
  director, no loadout: every move is rejected).
- **Owner-side, Stage 4**:
  - Director Blueprints: `Set AI Strategy` -> `Set AI Strategies` (an array); new `Set AI Selector`.
  - Any Blueprint using the controller's `Get Strategy` node: removed (read the director's `Strategies`).
  - Any profile or asset using the Coordinator strategy class: it no longer exists (put the strategies on a director).
  - MinMax `Top Moves Considered` / `Mistake Chance` and strategies' `Min Think Seconds` values are dropped: re-enter them on
    a Top N selector / the director.
- **Owner-side, Stage 5** (assets found referencing the profile):
  - `ConnectIt_UI_MainMenu` -- remove the AI-profile choice (`Match Settings > AI Profile`, the catalog's `AI Profiles`) and
    any `Get Opponent Profile` nodes; offer presets instead (one per opponent, e.g. Classic Easy / Hard).
  - `CI_AIProfile_PlaceRandomPiece`, `CI_AIProfile_Test` -- move their loadout and strategy onto an AI Director on the
    presets that should use them, then delete them. `CI_AIStrategy_PlaceRandom` (a strategy Blueprint) stays.
  - `CI_LevelConfig_Puzzle_Swap`, `CI_LevelConfig_Test` -- still hold profile data from before the stage / preset split;
    no match preset asset exists yet, so create the presets (with AI Directors) and set each level config's Default Match
    Preset. Resave both configs.
  - No UI now gets the opponent's profile from the GameState: show the AI's name from its PlayerState, or the preset's
    Display Name.
- Being cut off by the think time is logged at Log level, not as a warning (it happens every turn for a deep search); the
  warning is for "no strategy has a move yet".
- Top N's mistake is a pick among ranks **2..N** (a real mistake); MinMax's old one picked among 1..N, best included. Same
  feel at a slightly higher `MistakeChance`.
- Greedy Scorer ranks by the AI's **own** score change, not the operation's raw points (a move scoring for the opponent
  gains nothing).
