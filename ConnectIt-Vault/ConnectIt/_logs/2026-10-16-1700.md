## Request

Carry out the approved plan [design/ai-director-pipeline](../design/ai-director-pipeline.md): the director owns the AI's
setup, the coordinator becomes a fixed pipeline, strategies cache a best-so-far answer, selectors pick among answers, the AI
profile goes, win conditions become data assets. Built stage by stage; this note grows with each stage.

## Overview

- **Stage 0** -- plan moved into the vault; `design/composable-ai.md` marked partly superseded. Owner committed (b069416).
- **Stage 1** -- the MinMax search reports each completed depth's ranking as it runs, into a thread-safe progress holder the
  game thread can read at any time. Built; 32/32 tests pass. Owner committed (05abbe9).
- **Stage 2** -- candidates gain optional `Confidence` / `StrategyScore` / `Tags` / `SourceLabel`; every strategy keeps a
  best-so-far answer (`PublishBestSoFar`, `GetBestSoFar`, `IsDecisionFinished`); the MinMax strategy answers from its
  search's progress while it runs, with confidences. Built; 35/35 tests pass. Owner committed (31a6bb1).
- **Stage 3** -- selectors: a base class with one pipeline (endorse -> rank -> keep MaxCandidates) and the four first ones
  (First Available, Top N with mistake chance, Greedy Scorer, Weighted by Confidence). Built; 39/39 tests pass. Not wired in
  yet: the coordinator runs them from Stage 4.
