## Request

Board Shift's Down shift sorted ascending; owner asked to make rows run along X and columns
along Y consistently.

## Overview

- Root cause: `GridDirectionVectors` gave Up/Down a Y step while `GetTilesByDirection` walks
  Up/Down along X, so Board Shift's sort key was 0 for every tile on an Up/Down (and
  Left/Right) line — the sort was a no-op. The "\" diagonals were also inverted.
- **Superseded later the same session.** First attempt rewrote the direction table (X = row,
  Up = +X) from a misreading of "rows along X". The owner then clarified X is left-right and Y
  up-down, so the table was restored to its committed values and `GetTilesByDirection` was fixed
  instead (Up/Down → same X, Left/Right → same Y). See
  [2026-09-20-grid-x-horizontal-y-vertical-line-function-fixed](../_decisions/2026-09-20-grid-x-horizontal-y-vertical-line-function-fixed.md).
- **Not compiled** — the editor was open. Needs a build, then PIE check of all 8 directions.
