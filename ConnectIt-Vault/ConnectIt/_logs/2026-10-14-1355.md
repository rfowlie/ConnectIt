## Request

Smash-style level reuse: a level designed for Adventure, playable in multiplayer with a different setup chosen in the
menu. After discussing four options the owner chose to split the stage from the match.

## Overview

The level config now holds the stage only and names a default `UConnectIt_MatchPreset` (rules, player loadout, AI);
the menu can choose another preset. **Code written, deliberately not built**: the two existing level configs' old
values must be copied out with the current build first (owner chose to migrate by hand). Plan + status:
[design/stage-and-match-preset](../design/stage-and-match-preset.md).
