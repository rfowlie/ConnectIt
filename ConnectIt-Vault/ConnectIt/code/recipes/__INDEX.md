# game (ConnectIt module) — recipes index

Step-by-step task procedures. Governed by [[_core/_schema/_code|_core/_schema/_code.md]].

Generated by Dataview from each recipe's `task`, `status` and `reconciled` properties. (Needs the Dataview plugin.)

```dataview
TABLE WITHOUT ID file.link AS Recipe, task AS "Goal", status AS Status, reconciled AS Reconciled
FROM "ConnectIt/code/recipes"
WHERE schema = "recipes" AND file.name != "__INDEX"
SORT file.name ASC
```
