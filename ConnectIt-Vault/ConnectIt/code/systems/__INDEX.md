# game (ConnectIt module) — systems index

Per-flow narrative pages, each with a Mermaid diagram. Governed by [[_core/_schema/_code|_core/_schema/_code.md]].

Generated by Dataview from each flow's `summary`, `status` and `reconciled` properties. (Needs the Dataview plugin.)

```dataview
TABLE WITHOUT ID file.link AS Flow, summary AS "What it does", status AS Status, reconciled AS Reconciled
FROM "ConnectIt/code/systems"
WHERE schema = "systems" AND file.name != "__INDEX"
SORT status ASC, file.name ASC
```
