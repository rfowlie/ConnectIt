# ConnectIt/design/ — index of plans and decisions

Plans and the decisions behind the design notes in this folder. Notes here are schema-less (see [`__README.md`](__README.md));
only plans carry properties. Decision notes themselves live in [`../_decisions/`](../_decisions/__INDEX.md).

Everything below is generated by Dataview from the notes' properties, so it stays current without editing this file. (Needs the
Dataview plugin.) Plan properties are described in the [README](__README.md).

## Plans

Newest first, by the date the file was created.

```dataview
TABLE WITHOUT ID file.link AS Plan, file.cday AS Created, status AS Status, current_stage AS "Current stage", started AS Started, approved_on AS Approved, completed_on AS Completed, decision AS Decision
FROM "ConnectIt/design"
WHERE type = "plan"
SORT file.cday DESC, file.name ASC
```

### Plans still to do

```dataview
TABLE WITHOUT ID file.link AS Plan, status AS Status, current_stage AS "Current stage", stages AS Stages
FROM "ConnectIt/design"
WHERE type = "plan" AND (status = "not-started" OR status = "in-progress" OR status = "draft")
SORT file.cday DESC
```

## Decisions behind the design notes

Every design note (not a plan) and the decision notes it links to.

```dataview
TABLE WITHOUT ID file.link AS "Design note", filter(file.outlinks, (x) => contains(x.path, "_decisions/")) AS Decisions
FROM "ConnectIt/design"
WHERE type != "plan" AND file.name != "__INDEX" AND file.name != "__README"
SORT file.name ASC
```
