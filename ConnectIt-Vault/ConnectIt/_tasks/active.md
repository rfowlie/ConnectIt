| Learn about + decide on score windows for the MinMax search                    | 2026-10-02 | —      | active   | Design   | Owner wants to learn more before deciding (raised 10-02). Three related ideas: (1) a **caller-supplied root window** (alpha/beta) so a search can ask "is any move better than X?" and prune hard; (2) **PVS** (principal variation search) inside `TAlphaBeta` -- search the first move with the full window, scout the rest with a null window, re-search only on a fail-high; a pure speed-up; (3) **aspiration windows** -- each deepening iteration starts with a narrow window around the previous score, widening + re-searching on failure.
