# CLAUDE.md — UnrealEngineTools

The domain for **editor tools built for the Spell Thief project** in Unreal Engine 5: editor utility widgets,
Content Browser helpers, and the notes that review them.

## What's here

- [`AssetNamingKeeper.md`](AssetNamingKeeper.md) — review of the Asset Naming Keeper tool (an Editor Utility Widget
  that applies prefixes and suffixes to selected assets). Its source assets live in the game at
  `Content/AssetNamingKeeper/`.

## Status

Early. The Asset Naming Keeper review is from the binary assets only, not from running the tool in the editor; treat its
claims as unverified until tested.

## Rules

- A tool's source assets stay in the game repo. This domain holds the notes about them, not copies of the assets.
- Each tool gets its own note here, named after the tool.
