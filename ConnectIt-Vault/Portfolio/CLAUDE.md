## Standing constraints

- **No ex-employer specifics in anything public** — no studio or franchise names. Say "shipped
  titles as a technical artist."
- **Curated code excerpts only.** The public showcase is a separate `ConnectIt-Showcase` repo of
  hand-picked excerpts, not the game tree.
- **The main repo is currently public** (`github.com/rfowlie/ConnectIt`, checked 2026-09-30) and
  carries `ConnectIt-Vault/Development/` (personal career notes, which name the ex-employer).
  Resolve this before publishing anything — see the first task.
- **Honest claims:** dormant/stub/slice-1 plugins are described as such or omitted;
  `AdvancedSessions` is third-party — credit it, never claim it.
- **Time-box everything.** No refactoring, no finishing dormant plugins, no polish outside the plan's
  checklist (the perfectionism guard from `career-coach.md` §9).
- **Work only inside the repo** — plans and notes live here, not in `~/.claude/plans/`.
