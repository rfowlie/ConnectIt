## Request

Large architectural change: retire `AConnectIt_BoardManager`, move board state onto GameState, convert board request/rules handling to GameMode-owned `UObject`s, add a per-level config DataAsset, and remove the (confirmed-dead) shift pipeline.

## Overview

After investigation (registration model, replication constraints, dead-code confirmation) and three rounds of clarifying questions, executed a 5-phase plan:
- **Phase 0** — deleted the whole confirmed-dead shift pipeline: `UConnectIt_BoardShiftComponent`, `UConnectIt_ShiftAction`, `UConnectIt_TutorialShiftIntroAction`, `FConnectItRequestBoardShift`, and the `ConnectIt_Game_Shift`/`ConnectIt_Event_Shift` gameplay tags.
- **Phase 1** — moved `UConnectIt_BoardStateComponent` onto `AConnectIt_GameState` (stays a `UActorComponent`, per the user's explicit choice — only the replication constraint that pushed this decision was new, not the component type).
- **Phase 2** — moved `TileRegistry`/`PieceRegistry` onto `AConnectIt_PlayerController` (per-machine, at the time; later superseded — see `2026-09-09.md`).
- **Phase 3** — retired `AConnectIt_BoardManager` entirely, replaced by `UConnectIt_BoardRequestMediator` + `UConnectIt_BoardRules`, both plain `UObject`s constructed on `AConnectIt_GameMode` (structurally unreachable from any client, so the old `HasAuthority()` guard was removed rather than kept). Deleted `UConnectIt_ConfigComponent`/`UConnectIt_BoardManagerSubsystem`.
- **Phase 4–5** — added `UConnectIt_LevelConfigDataAsset` (per-level config, replaces `UConnectIt_ConfigComponent`) and `UConnectIt_LevelConfigSettings` (a `UDeveloperSettings`-backed level-name → DataAsset map).

Finished with a full documentation pass across the module's `Docs/` (since relocated to `../old/Source/ConnectIt/Docs/` by a later, unrelated vault reorganization) and folded durable facts into this vault's `game/high-level.md` and `game/code/AConnectIt_GameMode.md`.

- `[[game/high-level]]`, `[[game/code/AConnectIt_GameMode]]`, and the archived module docs under `../old/Source/ConnectIt/Docs/` — updated to describe the new architecture
