# _core/_clippings/

The **vault-wide** unprocessed capture dump — Obsidian Web Clipper output and other quick
captures, before triage.

Governed by [`_schema/_clippings.md`](_clippings.md). Everything here is
"not yet dealt with"; an empty folder is the goal state. Processing an item means moving
it to its real home (`data/raw/` for source material, with origin metadata intact) and
deleting it here.
