# _core/_questions/

The **vault-level** open questions — unresolved threads not scoped to a single domain.
One note per question, `<kebab-slug>.md`, living until it closes.

Governed by [`_schema/_questions.md`](../_schema/_questions.md). A domain's own open
questions live in `<domain>/_questions/`.

Seed this folder from the "Open questions" list in `ABOUT.md` as items get real notes.
