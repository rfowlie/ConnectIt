## Request

User asked to file a transcript ("Actions setup 1.m4a") as a `_discussions/` note, then —
once `_discussions` turned out to be an unschemed folder — asked to formalize it as a
proper schema (with a Workflows section and topic-threading instead of subfolders) and add
a `/process-discussion` skill to file transcripts into it. The transcript itself was
deferred to a later turn.

## Overview

Added `_discussions` as a full vault schema: one dated note per discussion (call,
brainstorm, transcribed conversation), organized by having each note link every topic it
covers back to the most recent prior `_discussions/` note that also covered it, instead of
a folder hierarchy. Built the matching template and a new skill,
`/process-discussion`, that takes a transcript and files it per that template — flagged in
the skill index as input-driven rather than a `process-*` sweep, so it isn't part of
`/process`'s combined run.
