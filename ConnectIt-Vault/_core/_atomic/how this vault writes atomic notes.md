# Overview

The reference for creating atomic notes in this vault. It is **meant to be edited
per-vault** — trim it, tighten the word limit, change the maturity tags — to get the
behaviour you want. The rulebook that governs the folder is
[`_schema/_atomic.md`](../_schema/_atomic.md); this note is the "how to think about it"
companion.

---

An **atomic note** (also called a **main note**) is the fundamental building block of a
digital Zettelkasten or personal knowledge network. Unlike a note that summarises a whole
article or covers several broad topics, an atomic note is a highly focused, self-contained
unit of thought.

An atomic note is defined by **three core strengths**:

1. **Singularity (one idea).** Each note limits itself to **exactly one idea or concept**.
   Split large topics into smaller, ordered units. Instead of one general note about a
   shoe style, you might have an atomic note strictly on "shoe anatomy" that refuses to
   discuss materials, style, or outfit pairing.
2. **Independence (self-explanatory).** An atomic note must be **independent and
   self-contained**, with a clear start, middle, and end. It carries all the context it
   needs, so opening it months or years later re-informs you without chasing other notes
   or outside background.
3. **Freedom to connect.** All atomic notes live **together in a single folder**. Because
   they aren't locked into rigid category folders, they mingle and link with notes from
   entirely different topics — which is what sparks creative connections.

## What becomes an atomic note

- **Fleshed-out source insights.** After rough source notes on a book, video, or article,
  take the most interesting ideas and expand them into polished individual notes.
- **Recurring themes.** A pattern that shows up across multiple sources gets its own note
  that names, defines, and summarises it.
- **Your own thoughts.** No external source required — a personal idea, preference, or
  question is fair game.

## Best practices

- **Write in your own words.** Don't paste from the source; rewriting forces active
  learning and deeper digestion.
- **Keep it short and focused.** Aim for a "mini-essay" **under 1000 words** — still a
  single, tightly-scoped read, even if it no longer fits on screen without scrolling.
- **Standardise the structure.** Date, a maturity status tag (`baby` / `child` / `adult`),
  a few high-level topic tags, the body, and a references section at the bottom.
- **Link heavily.** Connect to related atomic notes, and always link back to the source
  note so you never lose where the idea came from.
