# _core/_atomic/

The vault's **single atomic-notes pool** — one flat folder of single-idea notes, free to
link across every topic. There is exactly one of these per vault and it is here; a second
`atomic/` folder anywhere else is an error.

Governed by [`_schema/_atomic.md`](../_schema/_atomic.md). New to atomic notes, or tuning
how this vault does them? Read [`about-atomic-notes.md`](how%20this%20vault%20writes%20atomic%20notes.md).

- One idea per note, `<kebab-slug>.md`, named for the idea.
